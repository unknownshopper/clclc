Implementación dentro del sistema/servidor del cliente

Modalidad
Integración (cliente)
Volver al sistema
Este documento describe el alcance, requerimientos técnicos y condiciones para integrar el sistema de encuestas dentro del servidor/sistema del cliente. El objetivo es habilitar trazabilidad por sucursal y encuestador (mesero/cajero) conservando anonimato opcional para el cliente.

Alcance propuesto

Arranque previsto: 16 sucursales + 9 franquicias (25 unidades). La cantidad de encuestadores (meseros/cajeros) se confirmará posteriormente.
Componente Incluye
Encuesta optimizada CSAT 1–5, Atención 1–5, Tiempos 1–5, NPS 0–10, Comentario opcional y flujo condicional de contacto.
QR por encuestador URL única por mesero/cajero con sid + mid + k (token).
Trazabilidad Registro de sucursal, encuestador, fecha/hora y respuestas.
Privacidad Anonimato por defecto; nombre/teléfono opcionales. Contacto solo con consentimiento explícito.
Panel de resultados Dashboard y filtros por sucursal/encuestador/mes, listado de comentarios y casos con contacto aceptado.
Glosario (alcance)
CSAT: Customer Satisfaction Score. Escala de satisfacción (en esta propuesta 1–5).
NPS: Net Promoter Score. Pregunta “¿qué tan probable es que recomiendes?” (en esta propuesta 0–10).

Requerimientos de acceso (para implementar en su sistema)

Para avanzar se requiere acceso y visibilidad del flujo actual donde hoy vive la encuesta (mismo dominio donde apunta el QR actual).
Requerimiento Detalle
Acceso técnico al sitio Tipo de stack (WordPress / custom / etc.), URL del formulario actual y acceso a ambientes (staging/producción) si existen.
Repositorio o código Acceso a repositorio (Git) o entrega de código fuente (si aplica) para integrar el formulario y lógica de guardado.
Base de datos / almacenamiento Definir dónde quedarán las respuestas: DB del cliente, CRM, ERP o tabla específica; con estructura acordada.
Credenciales / llaves Si hay servicios externos (APIs, captcha, analítica), proveer credenciales temporales para desarrollo.
Contacto técnico Responsable del lado del cliente para validación de accesos, despliegues y pruebas.
Política de privacidad Texto de consentimiento para nombre/teléfono y canal de contacto (llamada/WhatsApp), con aprobación del cliente.
Nota
Si no se cuenta con acceso al código o no es posible modificar el sistema actual, se recomienda migrar a un módulo independiente (producto Unknown Shoppers). Esta propuesta es exclusivamente para la integración en su sistema.
Glosario (requerimientos)
CRM: sistema para administrar relación con clientes (contactos, seguimiento, incidencias).
ERP: sistema administrativo/operativo (ventas, inventarios, operaciones, reportes).
Staging: ambiente de prueba previo a producción.
Producción: ambiente en vivo usado por clientes.

Definición de identificadores (sid / mid / token)

Para asegurar trazabilidad se usan parámetros en URL por QR.
Ejemplo de URL por encuestador
https://cafelacabana.com/encuesta?sid=altabrisa&mid=mesero-12&k=TOKEN
sid Sucursal · mid Encuestador · k Token
Campo Responsable Definición
sid Cliente / Unknown Shoppers ID interno por sucursal/franquicia (ej. altabrisa, galerias).
mid Cliente / Unknown Shoppers ID por encuestador (mesero/cajero). Puede ser un consecutivo o clave interna.
k Unknown Shoppers Token por encuestador para reducir manipulación manual del URL.
Glosario (identificadores)
sid: identificador de sucursal/franquicia en el enlace del QR.
mid: identificador del encuestador (mesero/cajero) en el enlace del QR.
Token (k): clave asociada al encuestador para reducir manipulación manual del URL.

Tiempos de entrega (estimación)

El cronograma puede ajustarse según accesos y velocidad de validación del cliente.
Fase Descripción Tiempo
Fase 1 · Levantamiento Revisión del flujo actual, stack del sitio, definición de dónde se guardan respuestas y alcance final del panel. 2–4 días hábiles
Fase 2 · Implementación Integración del formulario, trazabilidad por QR (sid/mid/k), validaciones y guardado. 1–2 semanas
Fase 3 · Panel y despliegue Dashboard, filtros, exportables (si aplica), QA y salida a producción. 3–5 días hábiles
Glosario (tiempos)
Día hábil: día laborable (normalmente lunes a viernes).
